# BarengIn.Desktop.WinForms

Original Windows Forms screens (Login and Find a Ride) written by Calvin for the Module 7 class assignment. Kept unchanged as the reference design.

Windows Forms only runs on Windows. It compiles on macOS (`EnableWindowsTargeting`) but cannot be launched there. The cross-platform version that runs on macOS lives in [`../BarengIn.Desktop`](../BarengIn.Desktop).

Not part of `BarengIn.sln`; open `BarengIn.Desktop.WinForms.csproj` directly in Visual Studio on Windows.
