# BarengIn.Web (frontend)

This folder is intentionally empty for now.

The frontend framework decision is still open: **React + Vite** versus **Blazor WebAssembly**. We are waiting on confirmation from the teaching assistant before committing to either one. Creating a project structure now would quietly pick a winner, and the folder layouts for the two options have almost nothing in common.

Once the decision is made it gets recorded as an architecture decision record in [`docs/decisions/`](../../docs/decisions/). The real project structure is then scaffolded here in a follow-up pull request that references that record.

Until then, do not add framework-specific folders or dependencies to this directory.
